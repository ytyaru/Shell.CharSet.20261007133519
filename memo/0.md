つまり二つの1Byte文字セットを使い分け、それらを混在させる文書形式ファイルを作れば、1Byteで英文と日本語(漢字使えない)を記述できる。

以下のように文字セットを切り替える境目で開始と終了を意味するバイト値を設置せねばならないが。

```
<ja>私は</ja><en>C</en><ja>言語を使います。</ja><bin>0x00</bin><ja>のように生のバイナリ配列も扱えます。</ja>
```

更に漢字が使えないので実際は以下のようになるが。

```
<ja>わたし　は</ja><en>C</en><ja>げんご　を　つかい　ます。</ja><bin>0x00</bin><ja>の　ように　なま　の　バイナリ　はいれつ　も　あつかえます。</ja>
```

まるでポケモン構文だ。ついでに言えば英数字だけは半角で、日本語は全角。この違いによりガタガタになる。スペースも全角・半角があるなら尚更ガタガタになる。しかも日本語だと全角スペースしか使えない。半角スペースを使いたい場面もあるのに。たとえば字下げの時は全角にしたいけど、文節区切りのところでは半角スペースにしたいなど。何とかしたいが、英字などの半角文字を全角化すると読みづらいし。どうしたものか。
